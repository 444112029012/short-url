# 短網址服務｜團隊章程（專案版）

> 關閉審查必改項 **G0-R1／G0-R3**。本檔依本專案調整 RACI；無獨立 UI 產品時 UI/UX 列標「本專案不適用（API／導向為主）」。

## 一、專案適用原則
1. **文件先行**：至少達 G3 開工就緒才大量實作。
2. **資安左移**：安全部參與 G1–G5。
3. **全程追溯**：REQ／NFR／SEC 追溯到設計、PR、測試。
4. **審查獨立**：審查部只審不改。
5. **運作測試模式（本輪）**：使用者暫不參與日常拍板，但拍板事項仍登記於決策／退回追蹤表，待使用者恢復時補簽（見 G0-R4）。
