# 資安需求清單（SEC）：短網址服務

> ASVS 版本：**OWASP ASVS 5.0**；專案驗證等級：**Level 1**（見 [00-asvs-level-v0.1.md](./00-asvs-level-v0.1.md)）。  
> 「超出 L1」＝該 ASVS 條目在標準中為 L2／L3，但本專案因 REQ／隱私／R-03 仍列為必須或應該。  
> **G2 更新**：威脅欄已對接 `TM-xxx`（見 [04-threat-model-v0.1.md](./04-threat-model-v0.1.md)）。新增 SEC-016、SEC-017。  
> 驗證方式禁止空話；品保可據此建 `TC-xxx`。
