## 1. 範圍、資產與 DFD 引用

### 1.1 範圍內
建立短碼、短碼導向、點擊次數查詢、基本驗證／錯誤處理、觀測日誌（非業務明細）。

### 1.2 範圍外（不建模為需緩解之產品功能）
帳號／多租戶（OUT-03）、管理後台（OUT-11）、預覽頁（OUT-10）、點擊 IP／UA 明細（OUT-09）。

### 1.3 資產

| 資產 | 敏感等級 | 備註 |
|---|---|---|
| short_code ↔ long_url 對應（DS1） | 內部 | 完整性影響導向正確性 |
| click_count | 公開／內部 | MVP 無授權即可查 |
| 服務可用性（P1～P3） | 內部 | 小流量假設 C-04 |
| DS2 中可能之連線 IP | 內部（可能個資） | ≤14 日；非業務庫 |
| DB 連線憑證 | 機密 | 不得進版控 |

### TM-002 呈報文案（供總協調轉使用者）

> **D-06 高風險殘餘接受請求（SHORTURL／G2）**  
> 風險編號：TM-002（對應章程 R-03、資安需求 SEC-002）。  
> 內容：在 MVP 僅驗證 http(s) 格式、且依範圍外 OUT-10 **不實作**預覽／安全間隙頁的前提下，攻擊者仍可將外觀合法的 **https 釣魚或惡意連結**縮短為本服務短碼並散佈；受害者可能因短網址而降低戒心。  
> 已採緩解：協定／格式白名單、導向 Location 不可被請求參數改寫、短碼不可預測、建立／導向限流（計畫中）。  
> **無法在本範圍內將殘餘降至「中」以下。**  
> 請使用者書面表示：□ 接受本殘餘高風險（可附重新評估日，建議 G5 前再確一次）　□ 不接受 → 須開 CR 納入預覽頁或同等控制後再送 G2／G5。
