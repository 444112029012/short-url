# ADR-001：應用語言／框架

| 欄位 | 內容 |
|---|---|
| 狀態 | **已採納**（D-04，2026-10-07，方案 A：Go＋chi） |
| 日期 | 2026-10-07 |

## 背景

技術棧未定（C-02）。需選定實作 ShortUrlApp 的語言與 HTTP 框架，以支撐建立／導向／統計 API、單實例小流量、可觀測與安全標頭。

## 選項

### 方案 A：Go ＋ 標準庫 net/http 或 chi

- 優：單靜態二進位、併發佳、標準庫成熟、部署簡單（NFR-002／003）
- 缺：泛型／生態較嚴謹，開發者需熟悉 Go

### 方案 B：TypeScript ＋ Fastify

- 優：與 OpenAPI 工具鏈友善、開發速度快
- 缺：需 Node 執行時；型別／建置鏈較重

### 方案 C：Python ＋ FastAPI

- 優：開發快、OpenAPI 自動產生、可讀性高
- 缺：併發／部署需注意 worker 模型；單實例仍可接受

## 比較

| 維度 | A Go | B TS+Fastify | C Python+FastAPI |
|---|---|---|---|
| 演示部署簡度 | 高 | 中 | 中 |
| P95≤2s（小流量） | 易達 | 易達 | 易達 |
| 與方法規格對齊 | 介面清晰 | 清晰 | 清晰 |
| 團隊練手價值 | 高 | 高 | 高 |

## 建議傾向

**已採納方案 A（Go＋chi）**（D-04，2026-10-07）。方案 B／C 僅作歷史比較，不實作。

## 後果

- 已採納：目錄／模組邊界對齊 Component；CI 掃描器語言定為 Go。
- 未拍板前研發不得以「已定案」為由鎖死堆疊。
