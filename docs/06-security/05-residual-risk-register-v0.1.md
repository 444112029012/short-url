## 2. 高／嚴重殘餘呈報（D-06）

### 2.1 RR-001／TM-002 必須呈報

| 欄位 | 內容 |
|---|---|
| 風險 | 攻擊者將通過 http(s) 格式驗證的釣魚或惡意連結縮短為本服務短碼並散佈 |
| 為何仍高 | OUT-10 明確不實作預覽／安全間隙頁；格式白名單**不能**判斷內容是否釣魚 |
| 若拒絕接受 | 須 CR 納入預覽頁、網域聲譽或人工審核等控制後，複評殘餘 |
| 建議重新評估 | G5 上線前；或改為對外營運時（並重評 ASVS） |

### 2.2 呈報文案（可直接轉使用者）

```
主旨：【SHORTURL】D-06 請接受 G2 高風險殘餘 RR-001／TM-002（R-03 釣魚短網址散佈）

王昱殊 您好：

安全部於 G2 威脅模型中識別並緩解多數技術風險後，仍有一項殘餘風險為「高」，依章程須您書面接受方可讓 G2 資安前置完整：

• 編號：RR-001／TM-002（SEC-002；章程 R-03）
• 內容：在僅驗證 URL 為 http/https、且不實作預覽頁（OUT-10）的前提下，
  惡意行為者仍可把外觀合法的 https 釣魚／惡意連結縮短成我們的短碼來散佈。
• 已做：協定與格式白名單、導向目標不可被參數竄改、短碼不可預測、速率限制（規劃）。
• 無法宣稱：此風險已消除或已降至中以下。

請回覆其一：
A. 接受本殘餘高風險（建議註明重新評估日：G5 前）
B. 不接受 → 請指示是否開 CR 納入預覽頁或同等控制

安全部
日期：2026-10-07
```
