5. DoD 書面涵蓋程式／測試／文件／安全／CI／追溯／演示。  
6. 研發任務拆解以 WP／Task 骨架對齊 API operation 與公開方法，全表標 **待研發對齊**（研發清單未到位時之合理替代，不阻擋策略／DoD 送審）。
