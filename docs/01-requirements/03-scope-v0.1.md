# 範圍內外說明：短網址服務

> 與章程 v1.0 對齊並細化；變更須走 `CR-xxx` 並由使用者拍板（D-05）。

---

## 1. 範圍內（承諾）

| 編號 | 項目 | 細化說明 | 對應需求 |
|---|---|---|---|
| IN-01 | 建立短碼 | 系統產生唯一短碼；回傳短網址；不提供自訂短碼 | REQ-001、REQ-010、REQ-012 |
| IN-02 | 短碼導向 | HTTP 重新導向至建立時長網址 | REQ-002 |
| IN-03 | 點擊次數 | 成功導向時 +1；可查詢目前次數；無圖表／來源分析 | REQ-003、REQ-004 |
| IN-04 | 基本驗證 | http／https、非空、長度上限、短碼格式規則 | REQ-005、REQ-006、REQ-011 |
| IN-05 | 錯誤處理 | invalid／not_found 等明確錯誤；不洩漏內部資訊 | REQ-007、REQ-008、REQ-009 |
| IN-06 | 文件與流程 | G0–G6 文件手冊與關卡、資安／測試／維運章節 | NFR-004、NFR-006～NFR-008 |

## 2. 範圍外（未承諾）

| 編號 | 項目 | 細化／邊界說明 |
|---|---|---|
| OUT-01 | 自訂短碼／別名 | 使用者指定短碼字串；保留字／衝突策略皆不實作 |
| OUT-02 | 分析儀表板 | 圖表、趨勢、Referer、地理、裝置、UTM 等 |
| OUT-03 | 帳號／多租戶／權限 | 註冊登入、API Key 帳號體系、角色權限、「我的連結」 |
| OUT-04 | 付費／計費 | 方案、配額、發票 |
| OUT-05 | 到期與批次 | 短碼 TTL 自動失效、CSV 批次匯入匯出 |
| OUT-06 | 原生客戶端 | 行動 App、瀏覽器外掛 |
| OUT-07 | 商用級高可用 | 多區、正式 SLA、大型公開流量工程 |
| OUT-08 | 第三方身分 | OAuth／社群登入 |
