# Definition of Done（DoD）：SHORTURL

> 適用：功能任務／PR／里程碑「可宣告完成」之最低書面標準。  
> 零現金預算；開源工具。技術棧 D-04：Go＋chi／SQLite／base62×8 CSPRNG。

---

## 1. 總則

一項工作（WP／任務／PR）僅在下列**適用區塊**全部勾選通過（或不適用且附理由）時，方可標 Done。  
「不適用」須寫明理由（例如純文件任務無程式區塊）。

## 2. 程式（研發）

| # | 準則 | 驗證 |

| P1 | 實作對齊方法規格公開方法之職責／錯誤碼／前後置 | 碼審＋對應 UT |

| P5 | 無訪客 IP／UA 持久化欄（SEC-004） | schema／IT |
| P6 | ErrorMapper 對外無堆疊／路徑／SQL（SEC-003） | UT-ERR |
| P7 | 限流行為符合文件門檻或已登錄殘餘（SEC-007） | UT-RL／E2E-05 |
| P8 | 變更含必要註解／介面穩定；無已知 Blocker | PR 檢查 |
