# CR-002｜CI 改用 Go 1.27.2，gosec 暫行釘上游未發行 commit

## 1. 摘要

`setup-go` 的 `1.27.x` 自動解析到 Go 1.27.2，gosec v2.29.0 讀不了 export data v5，`sast-gosec` 全 repo（含 main 2e54f7e）轉紅。改釘 1.27.1（#14）後 `sca-govulncheck` 擋下 5 個可達標準函式庫漏洞（GO-2026-6603／6611／6612／6613／6617，皆於 1.27.2 修正）。目前無支援 1.27.2 的 gosec 發行版（上游 securego/gosec#1774）。本 CR 改用 Go 1.27.2，gosec 釘上游 master commit 707f2271f66579a18e1da25794b1e8012247274b，掃描門檻不放寬。
